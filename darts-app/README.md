# KI-LEAGUE 対戦表・スコアシートアプリ

DARTS BAR ITSUKI のリーグ戦（KI-LEAGUE）用の、紙のスコアシートをそのまま
アプリにしたものです。**参加メンバーを選ぶだけで13試合のオーダーを自動で組み**、
レーティングから各試合の勝率（勝てる試合か／捨て試合か）まで出します。

## 1. できること

- 紙のスコアシートと同じ見た目の入力画面（HOME⑩〜①／13ゲーム／AWAY①〜⑩）
- マス目を押すだけで出場者と勝敗を入力 → 獲得ポイント・勝利ポイント(2P)・合計ポイントを自動計算
- 選手ごとのレーティング(Rt)・PPD・MPR 登録（どれか1つでOK。残りは自動換算）
- **オーダー自動編成**：S=1人 / D=2人 / T=3人 / G=4人 の必要人数に合わせて自動割り振り
  - 出場数が偏らないように上限・下限つき
  - 「くじ」の試合(⑤⑩)はランダム
  - 固定(鍵)した選手・結果を入れた試合はそのまま
  - 勝率を計算し、勝ち星と「節に勝つ確率」がいちばん高くなる並びを探す
- 試合ごとの予想勝率と判定（勝ち計算／優位／五分／劣勢／捨て試合）
- **順番はレーティングの高い順**：参加メンバーの①〜⑩も、各試合で投げる順番も、
  Rtの高い人から自動で並びます（Rtを直すと並びも付け直されます）
- チーム順位・選手成績（出場数・勝率）
- 印刷（A4横）とCSV書き出し

## 2. 雛形（13ゲーム）

| No | GAME | 人数 | R | コイン | | No | GAME | 人数 | R | コイン |
|----|------|-----|---|-----|-|----|------|-----|---|-----|
| ① | 501 | D | 15R | 200 | | ⑧ | CR | G/T | 20R | 200 |
| ② | CR | D | 20R | 200 | | ⑨ | 701 | D | 15R | 200 |
| ③ | 901 | T | 20R | 200 | | ⑩ | CRくじ | S | 20R | 200 |
| ④ | CR | T | 20R | 200 | | ⑪ | 501 | D | 15R | 200 |
| ⑤ | 501くじ | S | 15R | 200 | | ⑫ | CR | T | 20R | 200 |
| ⑥ | FREEZE | D | 15R | 400 | | ⑬ | 901 | T | 20R | 200 |
| ⑦ | 901 | G/T | 20R | 200 | | | | | | |

⑦⑧は **参加人数に合わせて自動で切り替わります**。

- 参加が **3人以下** → 4人は出せないので **トリオス(T・3人)**
- 参加が **4人以上** → 雛形どおり **4人制(G)**

HOMEとAWAYで人数が違うときは少ない方に合わせます（試合の形式は両チーム共通のため）。
4人以上いてもトリオスにしたいときは、自動オーダー画面のチェック、または
シートの人数欄「G*」を押せば切り替えられます。人数を減らして4人→3人になった場合は、
その試合の4人目（レーティングがいちばん低い人）が自動で外れます。
結果を入れた試合と固定した試合は、あとから人数が変わっても形式はそのままです。

全13試合ののべ出場枠は **32人分**（⑦⑧がトリオスなら30人分）。

## 3. 使い方

1. **チーム・選手** タブでチームを作り、選手を登録する
   （Rt だけ／PPD・MPR だけ／両方、どれでも可）
2. **対戦** タブで節・日付・相手を入れて対戦を作る
   （相手が未登録でも「相手の想定Rt」を入れれば計算できます）
3. **参加メンバー** で、その日来ている人を押す（①②③…はレーティング順に自動で並びます。
   ⑦⑧の人数もここで決まった参加人数に合わせて自動で切り替わります）
4. **自動オーダー** で「オーダーを組む」→ 予想勝率を見て「この編成で決定」
   （気に入らなければ「別の案を出す」で別案）
5. **スコアシート**（または試合ごと入力）で勝敗を押していく → ポイントは自動計算
6. 終わったら **印刷** か **CSV**。**成績** タブで順位と選手成績が見られます

## 4. 計算のしくみ

### レーティング → 種目ごとの強さ
PPD（ゼロワンの1本あたり得点）とMPR（クリケットの1ラウンドのマーク数）を、
DARTSLIVE の Rt 表に合わせて連続値の Rt に換算します（`backend/rating.py`）。
片方しか入っていなければ Rt から逆算します。これで
「01は強いがクリケットは苦手」といった得手不得手が反映されます。

### チーム力
交互に投げるので基本は参加者の平均。ただし上がりを任せられる人がいると
多少強くなるため、最大値へ少しだけ寄せます（`ACE_WEIGHT = 0.25`）。

### 勝率
`勝率 = 1 / (1 + exp(-(自分 - 相手) / ばらつき))`
ばらつきは種目で変えています。20Rや人数の多い試合は実力差が出やすく（小さめ）、
FREEZE は運の要素が大きい（大きめ）。3〜97%に収めます。

### 「勝てる試合か」を加味する自動編成
13試合の勝敗から節の勝敗が決まるので、各試合の勝率から
**何勝できるかの分布（ポアソン二項分布）** を出し、
`合計ポイント期待値 = 勝ち星の期待値 + 2P × 節に勝つ確率`
を最大にする組み合わせを焼きなまし法で探します（`backend/lineup.py`）。
その結果、

- 格上相手 → 勝てそうな試合に上手い人を集め、勝てない試合は捨てる
- 格下相手 → どの試合も五分を切らないように散らす

という配分が自動的に出てきます。目的は「勝ち星の期待値」「節に勝つ確率」にも
切り替えられます。

相手のオーダーが未定のときは、相手の参加メンバーからその人数が出ると考えた
期待値を相手のチーム力として使います。

## 5. 動かし方

```bash
cd darts-app
pip install -r requirements.txt
uvicorn backend.main:app --reload      # http://localhost:8000
```

スマホから使うときは、同じWi-FiでPCのIPアドレス（例 `http://192.168.1.10:8000`）を開きます。

### テスト

```bash
cd darts-app
python -m pytest tests -q
```

### データの保存先

SQLite（既定は `darts-app/darts.db`）。環境変数で変えられます。

| 環境変数 | 意味 |
|---------|------|
| `DARTS_DATA_DIR` | データの置き場所（Renderの永続ディスクなら `/var/data`） |
| `DARTS_DB` | DBファイルのパスを直接指定 |
| `FIREBASE_STORAGE_BUCKET` / `FIREBASE_SERVICE_ACCOUNT` | 設定するとFirebase Storageに自動バックアップ・復元（無料プランでもデータが消えない） |
| `DARTS_CLOUD_PATH` | Firebase上の保存パス（既定 `darts/darts.db`） |

## 6. 画面まわりのメモ

- スコアシートのマス目を押す＝出場、勝敗の列を押す＝勝ち負け（もう一度押すと取り消し）
- マス目の数字はその試合で**投げる順番**（1番手・2番手…）。レーティングの高い人が先です
- 「試合ごと入力」では選手を**固定**できます。固定した人は自動編成でも動きません
- 結果を入れた試合は、組み直しても並びが変わりません
- ログイン機能はありません。店内・チーム内で使う前提のアプリです。
  外部に公開するときは、URLを共有する相手に注意してください
